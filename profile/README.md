> **THE FREE NT OPERATING SYSTEM.**

Welcome to **LiberNT**, a free NT operating system built out of love for the NT architecture. The name says it: *liber* is Latin for **free**.

Started and maintained by **[Ahmed Arif](https://github.com/ahmedarif193)**, LiberNT targets **Windows® 11 compatibility** on **amd64, arm64 and riscv64**, with room for freestyle and experimental features.

We believe an operating system should be **stable. Reliable. Efficient.**

And free, for everyone, every day.

---

### ◈ OUR MISSION

**A system that stays maintainable in the long run.**

LiberNT brings extensive work on kernel-space components and drivers, aimed at stability and modern hardware. It should run on embedded devices too, and support every feature a modern operating system should have.

Windows 11 is the reference. We don't guess.

We ask:

> **“What does NT actually do?”**
