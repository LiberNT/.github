LiberNT is a free NT operating system, built out of love for the NT architecture. It targets Windows® 11 compatibility on amd64, arm64 and riscv64. LiberNT is a fork of ReactOS with extensive changes to kernel-space components and drivers, aimed at stability and modern hardware.

| Repository | What it is |
|------------|------------|
| [LiberNT](https://github.com/LiberNT/LiberNT) | Operating system source code |
| [libernt-build-toolchain](https://github.com/LiberNT/libernt-build-toolchain) | Prebuilt build toolchain (RosBE) for Windows, Linux and macOS |
